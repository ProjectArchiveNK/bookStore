## че надо

1. в карзине при нажатии на кнопку оформить заказ открывается тг с нужным текстом (какая книга, рефиралка, цена и тд) + как то отпровлять мне инфу об этом мб на почту сообще приходит с той же инфой
2. при нажатии на карточку открыается страница этой карточки (обернуть компонент карточки в линк)

## Colors

- primary: #4361ee (основной)
- primary-dark: #3a56d4 (более темная версия)
- secondary: #7209b7 (доп цвет)
- accent: #f72585 (незабываемый акцентный цвет)
- success: #4cc9f0 (цвет выгодной операции)

## Typography

- Главный заголовок - `32px` (H1)
- Заголовок раздела - `28px` (H2)
- Подзаголовок - `24px` (H3)
- Небольшой заголовок - `20px` (H4)
- Обычный текст - `16px`
- Маленький текст - `14px`
- Дополнительный текст - `12px`

## тень - box-shadow: 0 2px 8px rgba(0, 0, 0, 0.15);

## жирность

400 — обычный
500 — немного жирнее
600 — полужирный
700 — жирный

## инфа

- фронт на версель, бэк на рендер, бд на монго бд, фотки на Cloudinary Free
